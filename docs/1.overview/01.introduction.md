# Introduction

## What this is

An enterprise-grade, **multi-tenant SaaS microservices boilerplate**. It gives a team a
running starting point — authentication, authorization, tenant management, an API gateway,
local orchestration, and a web UI — so feature work can begin without rebuilding the
plumbing.

The backend is **.NET 9** following DDD/SOLID with a lightweight modular framework. The
frontend is **Angular 21**. Local development is orchestrated with **.NET Aspire**.

## Who it's for

- **Platform teams** bootstrapping a new SaaS product who want sensible defaults over a blank solution.
- **Engineers** who need a reference for the modular service layout, auth, and testing conventions.

## Scope at a glance

| Capability | Status |
|------------|--------|
| Identity — users, roles, permissions (RBAC) | Implemented |
| Authentication — OpenIddict OAuth2/OIDC | Implemented |
| Multi-tenancy — tenant management | Implemented |
| API gateway, orchestration, observability | Implemented |
| Notifications | Planned (service scaffolded) |
| Payments | Planned (service scaffolded) |

> Communication between services is **synchronous HTTP** today. Async messaging (Kafka/Outbox)
> and gRPC are not implemented.

## Tech stack

**Backend (.NET 9)**

| Area | Technology |
|------|-----------|
| Orchestration | .NET Aspire 9.5 |
| API gateway | YARP (via ServiceDiscovery.Yarp) |
| Identity / OAuth2 | OpenIddict 7.2 |
| ORM | EF Core 9 (SQL Server) · MongoDB.EntityFrameworkCore 9.1 |
| Validation / mapping | FluentValidation 12 · Mapster 10 |
| API docs | Scalar (OpenAPI) |
| Observability | OpenTelemetry (OTLP exporter) |
| Tests | MSTest |

**Frontend (Angular 21)**

| Area | Technology |
|------|-----------|
| UI | Bootstrap 5.3 · ngx-bootstrap 21 · Bootstrap Icons |
| Auth client | oidc-client-ts 3.4 |
| API clients | NSwag-generated proxies |
| Tests / tooling | Vitest · Playwright (e2e) · Storybook |

**Datastores:** SQL Server 2022 (relational), MongoDB 8.0 (document).
