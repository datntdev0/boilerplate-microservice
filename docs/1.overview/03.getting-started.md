# Getting Started

A quick path to a running local environment. Commands assume the repository root unless noted.

## Prerequisites

- .NET 9 SDK
- Node.js (for the Angular app and e2e tests)
- Docker (for local SQL Server + MongoDB)

## 1. Start local infrastructure

```bash
docker compose -f deploy/dockercompose.local.infra.yml -p datntdev_microservices_infra up -d
```

Starts SQL Server 2022 and MongoDB 8.0.

## 2. Apply migrations & seed data

```bash
dotnet run --project ./srcs/infra/Migrator/datntdev.Microservice.Infra.Migrator.csproj
```

Creates the relational schemas, MongoDB collections, and seeds the default admin account.

## 3. Run the backend (Aspire)

```bash
dotnet run --project ./srcs/infra/Aspire/datntdev.Microservice.Infra.Aspire.csproj
```

Launches all services, the gateway, and the identity provider, with the Aspire dashboard for logs/traces.

## 4. Run the frontend

```bash
cd srcs/apps/Angular
npm install
npm start          # dev server
```

## Testing

```bash
# Backend unit/integration tests (with coverage)
dotnet test --no-build --settings .runsettings

# Angular unit tests (headless)
cd srcs/apps/Angular && npm run test:ci

# End-to-end (Playwright)
cd e2e && npm ci && npx playwright install --with-deps && npx playwright test
```

## Other useful commands

```bash
dotnet build datntdev.Microservice.slnf      # build the solution
cd srcs/apps/Angular && npm run nswag         # regenerate TS API proxies from backend
cd srcs/apps/Angular && npm run storybook:start
```
