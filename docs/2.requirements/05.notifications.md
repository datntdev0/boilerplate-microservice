# Notification Requirements

> **Status: Planned.** The Notify service is scaffolded (project + MongoDB context) but has no
> entities or endpoints yet. This document captures intended scope to guide future work.

## Purpose

Deliver notifications (e.g. email, in-app) to users in response to platform events.

## Actors

- **Other services** — raise notification requests.
- **End user** — receives notifications.

## Intended functional requirements (draft)

- Accept a notification request (recipient, channel, template, payload).
- Send through one or more channels (email first; in-app/others later).
- Record delivery status for traceability.

## Constraints & NFRs (draft)

- Should not block the calling flow; delivery is expected to be asynchronous once messaging is introduced.
- Persistence in the Notify service's document store.

## Out of scope

- Defined when this service is implemented. Specify concrete features via the ScrumAI workflow
  under `.scrumai/features/`.
